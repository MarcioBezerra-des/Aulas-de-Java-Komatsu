# Documentação do Repositório: `Aulas_18_08_2025`

Este repositório contém uma coleção de projetos e exemplos em Java desenvolvidos para fins de estudo, focados em conceitos fundamentais da Programação Orientada a Objetos (POO).

## Estrutura de Pastas

### Construtores
* **Foco**: Demonstração do uso de construtores, incluindo sobrecarga de construtores para inicialização flexível de objetos.
* **Projeto Principal**: `PrecoDeProduto.java` - Um exemplo simples que modela um produto com diferentes formas de instanciação.

### Sobrecarga
* **Foco**: Exploração do conceito de sobrecarga de métodos (method overloading).
* **Projeto Principal**: `Soma.java` - Uma classe utilitária que implementa um método `somar` com diferentes assinaturas para operar com tipos e quantidades distintas de dados.

### Sobreposição e Polimorfismo
(Esta seção será atualizada com novos projetos e exemplos que aprofundam os conceitos de sobreposição de métodos (@Override) e polimorfismo em cenários mais complexos.)

### Desafio Extra
* **Foco**: Aplicação prática de conceitos de POO como herança e polimorfismo para resolver um problema de negócio.
* **Projeto Principal**: `BonusSalarial.java` - Um sistema que calcula bônus salariais para diferentes tipos de funcionários, mostrando como o polimorfismo permite tratar objetos de classes derivadas de forma uniforme.
